# Amazon Clone (Vanilla JavaScript)

A fully responsive, modular e-commerce web application inspired by Amazon. Built with modern JavaScript (ES6+), custom backend integration via Fetch API, persistent state management, and an interactive checkout experience.

## Features
- **Dynamic Product Catalog:** Asynchronously fetches product catalog data and renders items dynamically.
- **Cart Management:** Add, update quantities, and remove items with persistent browser storage (`localStorage`).
- **Delivery Options:** Configurable shipping dates and pricing dynamically recalculating the order total.
- **Asynchronous Architecture:** Implemented `fetch`, Promises, `async/await`, and comprehensive `try...catch` error handling for backend communication.
- **Modular Codebase:** Organized using ES6 modules (`import`/`export`) separating data models, UI logic, and utilities.

## Tech Stack
- HTML5 & CSS3
- JavaScript (ES6 Modules, Async/Await, Fetch API)
- Day.js (Third-party date library)
- LocalStorage API
